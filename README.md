## 🔒 **Freecam Server-Sperren (Server Restrictions)**

Server-Betreiber können ihren Server per Pull Request für das Freecam-Modul sperren lassen. Wenn ein Server in der Sperrliste eingetragen ist, wird Freecam auf dem Server clientseitig blockiert und in der Benutzeroberfläche mit einem Schloss-Symbol gesperrt:

1. Öffne die Datei [`freecam-restrictions.json`](freecam-restrictions.json).
2. Trage deine Hauptdomain unter `disallowed_servers` ein (z. B. `"deinserver.net"`). Subdomains wie `play.deinserver.net` sind automatisch enthalten.
3. Erstelle einen **Pull Request** auf GitHub.
4. Nach dem Merge wird die Einschränkung automatisch auf allen aktiven Clients übernommen.
