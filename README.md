## 🔒 **Server-Sperren (Server Restrictions)**

Server-Betreiber können ihren Server per Pull Request für Module wie Freecam sperren lassen. Wenn ein Server in der Sperrliste eingetragen ist, wird das entsprechende Modul auf dem Server clientseitig blockiert und in der Benutzeroberfläche mit einem Schloss-Symbol gesperrt:

1. Öffne den Ordner [`server-restrictions/`](server-restrictions/) und wähle die Modul-Datei (z. B. [`server-restrictions/freecam.json`](server-restrictions/freecam.json)).
2. Trage deine Hauptdomain unter `disallowed_servers` ein (z. B. `"deinserver.net"`). Subdomains wie `play.deinserver.net` sind automatisch enthalten.
3. Erstelle einen **Pull Request** auf GitHub.
4. Nach dem Merge wird die Einschränkung automatisch auf allen aktiven Clients übernommen.
